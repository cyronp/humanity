# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, welcome newcomers, accept constructive criticism, and focus on what is best for the project. Harassment and discriminatory behaviour are not tolerated.

To report a violation, open a private security advisory at <https://github.com/cyronp/humanity/security/advisories/new> and mark it as a conduct report. Maintainers will review it confidentially.
